# Streamer (TikTok / YouTube / Twitch)
FFmpeg-based. Loops a video, a picture, or a live web page (the SpectatorCamera preview) to any of
TikTok LIVE, YouTube Live and Twitch, each switchable true/false, with text, image and video overlays.
Has a small web panel to paste stream keys manually and press Start/Stop.
See ../docs/STREAMING.md and ../README.md (step 6).
